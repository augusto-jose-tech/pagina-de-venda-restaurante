# 🍽️ Página de Venda - Restaurante demo

Um protótipo moderno e responsivo de landing page desenvolvido para a apresentação de cardápios digitais, otimização de conversão e simulação de fluxos de atendimento para restaurantes.

---

## 🎯 Objetivo do Projeto
Este repositório foi construído para servir como ambiente de demonstração técnica e portfólio. O foco principal está na aplicação de boas práticas de desenvolvimento front-end, componentização visual limpa e design totalmente focado na experiência do usuário (UI/UX).

---

## 🚀 Tecnologias Utilizadas

O projeto foi estruturado utilizando as seguintes tecnologias:

* **HTML5** — Estruturação semântica, foco em acessibilidade e SEO.
* **CSS3** — Estilização moderna, uso de layouts flexíveis (Flexbox/Grid) e design responsivo.
* **JavaScript (Vanilla)** — Lógica de interatividade e controle das simulações da página.

---

## 📋 Funcionalidades Principais

* 📱 **Design Mobile-First:** Interface totalmente otimizada para celulares, tablets e computadores.
* ⚡ **Navegação Fluida:** Transições e rolagens suaves projetadas para manter o engajamento do usuário.
* 🛠️ **Protótipo Interativo:** Estrutura pronta para testes rápidos de usabilidade e fluxos de navegação.

---

## 🔧 Como Executar o Projeto Localmente

Para baixar os arquivos e rodar o projeto na sua máquina de desenvolvimento, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pagina-de-venda-restaurante
   ```

3. **Abra a aplicação:**
   * Dê um duplo clique no arquivo `index.html` ou utilize uma extensão como o *Live Server* no VS Code.
